Debt engine · live Jev run

Every Jev call, and what it decides

  1. Step 1

    Jev answers

    One call for each message. Only yes/no questions. Each answer is a number from 0 to 1, and 0.5 or more counts as yes.

  2. Step 2

    The rules start and pay debts

    A question owes an answer. A claim owes a reason. A reason owes a fair reply. A new option owes a reply.

  3. Step 3

    The stage sets the target

    Open: 1 option. Test: 2 or more. Close: the person asks to close, or only closing debts are left.

  4. Step 4

    The need picks the persona

    The newest due debt that the AI can act on. Its promise picks the persona.
